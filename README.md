# Portfólio — Alessandro Gava

Meu primeiro projeto de desenvolvimento web: um portfólio pessoal
para apresentar meus projetos e acompanhar minha evolução.

🌐 [Acesse o site](https://aleezmzk.github.io)

## Tecnologias utilizadas

- HTML: estrutura e conteúdo.
- CSS: aparência e adaptação para diferentes tamanhos de tela.

## O que pratiquei

- Organização de uma página com HTML semântico.
- Estilização com CSS.
- Layout responsivo com Flexbox, Grid e media queries.
- Navegação entre seções da página.
- Publicação com GitHub Pages.

## Como visualizar

Acesse o site pelo link acima ou baixe os arquivos
e abra o index.html no navegador.
